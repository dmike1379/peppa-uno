# Peppa UNO — Image Assets

Replace any `.svg` file with your own art (PNG, JPG, or SVG all work — just update the filenames in the game code if you change the extension).

## avatars/
One file per character. These show as player profile pictures in the game.

| File | Character | Suggested AI prompt |
|------|-----------|---------------------|
| `peppa.svg` | Peppa Pig | Linnea's avatar — merge with Peppa |
| `daddy-pig.svg` | Daddy Pig | Mike's avatar — merge with Daddy Pig |
| `george.svg` | George Pig | Peppa's little brother |
| `mummy-pig.svg` | Mummy Pig | Peppa's mum |
| `suzy-sheep.svg` | Suzy Sheep | Peppa's best friend |
| `rebecca-rabbit.svg` | Rebecca Rabbit | School friend |
| `danny-dog.svg` | Danny Dog | School friend |
| `pedro-pony.svg` | Pedro Pony | School friend |

**Recommended size:** 200×200 px, circular crop.

## cards/
These appear on the actual UNO cards.

| File | Used on |
|------|--------|
| `card-back.svg` | The back of every card |
| `wild.svg` | Wild cards (center art) |
| `wild-draw-four.svg` | Wild Draw 4 cards (center art) |

**Recommended size:** 160×240 px (portrait).
